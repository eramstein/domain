**Action queue** — When an NPC wants to perform an action (either autonomously or via an order), and that action prerequisites are not met, the NPC tries to figure out a sequence of actions that lead to the target action. For example, if the target action is 'collect-resource' in 'forest-clearing', and the character is not in 'forest-clearing', it first moves there. Then, if it can still perform 'collect-resource', it executes it, else it remembers to do it next turn.
